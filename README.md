MÓDULOS PARA EL ainvarCMS

Se crean 7 módulos:
- Agenda
- Catalog
- forms
- gallery
- i18n
- news
- redirects

Para instalarlos ir a la sección Módulos, subir el zip correspondiente y pulsar en instalar. Luego hay que activar el módulo y ya está funcionando. El módulo de idiomas (i18n) ya está instalado por defecto y no se puede eliminar.
